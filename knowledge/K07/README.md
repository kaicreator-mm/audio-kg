# K07 声学与听觉知识候选包（v0.1.0）

本目录是正式 MODULE 范围的完整候选，不是已接受知识或运行时。冻结 L1 的 51 条当前发现入口逐条保留：51 条专业命题、51 个条件、51 个证据记录、51 个案例组、204 个四视角案例，33 个正式候选来源；合计 441 个记录、161 条类型关系、236 条绑定。关系包含 8 条必要依赖 H、51 条可选导航 O；H 只提供限定的必要知识，不证明提供方条件满足。所有案例为明确的合成预期见证，而非观察结果。

## 如何使用
- [candidate.json](candidate.json)、[qualification.json](qualification.json)、[controller-input.json](controller-input.json)：精确版本引用、条件、限制、资格、正反与正逆案例、H 闭包；复用 F00 有界验证及发现读者。根目录运行：
  - `node tools/validate-knowledge.mjs knowledge/K07/controller-input.json 773e64ff07c864a7439cc523c8c81c502fc2c680 K07.01.01.03`
- [命题作者表](claim-authoring.tsv)：逐命题人工表达的谓词、适用条件、限制、正向与逆向问题；构建脚本仅离线作者工具，不能在消费端重新封印资格。
- [发现索引](../../queries/K07/discovery-index.json)：直接回答 D 和支持 S 单独保留，S 不提升为直接根，不把局部子问题当完整 CQ。
- [能力索引](../../queries/K07/capability-index.json)：8×7 共 56 格（P27/S14/C15），每格给具体任务/条件、候选命题和反例。C 不是可执行权限。
- [历史路由](../../queries/K07/legacy-routes.json)、[拆分路由](../../queries/K07/split-routes.json)：48 条历史入口与 7 条受影响开放拆分路由；保留待确认外域谓词，不声明等价/关闭。外域 K01/K05/K08/K10/K17/K19 等尚未形成正式提供者；角色接口和外域路由只是候选导航，不生成假定存在的跨域 H/O 目标。
- [来源定位与限制](../../sources/K07/provenance.json)：35 个历史登记来源，33 个实际支持源；S459 复访阻断，S465 仅标准版本元数据，不作为直接支撑。S450 为公共摘要，S447/453/460/462 只按摘要。来源权利 UNKNOWN_NO_IMPORT；无新外部文献抓取，不把历史已读升格成当前已读。共享 Source 采用本模块的唯一正式候选记录，未来模块复用精确版本，不重定义或转移领域知识所有权。
- [有限领域流程/状态/编辑记录](domain-workflows.json)：五个 P/A02 条件化知识流程，60 个本地有类型记录、69 条关系，5 个明确证据变更事件；一个可编辑频谱参数及报告版本示例。各步仅提出候选，条件缺失返回 UNKNOWN 或 STOP。仅为模块局部可验证语义形状，非 F00 通用引擎接口；统一跨域消费仍需 T07 明确验证并保持受审资格。
- [验证说明](../../docs/validation/K07/README.md)。

## 边界
没有实际音频、声场测量、人体/临床诊断、风险释放、真实权限、外部工具执行、LLM 效能试验或生产数据库。K07-AC51 的闭合拓扑仅说明可能回路，不证明实际振荡；场地操作由 K19 处理。听力突然下降停止试听、寻求及时医疗评估。未获得的条件和来源资格不能被模型得分或角色标签补足。候选受独立专业审核和精确合并门控；本包不会自动设置 acceptedClaims。
