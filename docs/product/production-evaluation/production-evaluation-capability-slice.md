# 音乐制作状态、可编辑产物和评价闭环（L1 专项）

DRAFT；是领域需求与例证，不是运行时架构或正式schema。关联 K09/K10 候选ID，引用K08原理及K12后续工具版本；复用 X01/X03/X04 的制作后期切片 PE-A01。场景：授权歌曲工程需仅修订副歌人声中一段音准/齿音问题，保持其他部分及既有自动化；成品、独立stem和可编辑工程均须交付。未提供实际工程或录音，所有状态/观测是合成预期。

## 候选状态与不变量
| 起始→结果 | 前提及输出 | 失败/拒绝 |
|---|---|---|
| BASELINE → ANALYZED | 权限、工程及素材身份/版本、目标时间段与评价协议已登记；分析结果绑定输入 | 缺素材/未授权/目标不明确→BLOCKED或UNKNOWN，不执行编辑 |
| ANALYZED → CANDIDATE | 原件保护；候选引用基线、明确编辑区间、处理配置与受影响依赖 | 不可保护原件、工具不支持局部语义或状态冲突→拒绝修改 |
| CANDIDATE → RENDERED | 导出指定范围和格式，记录实际输出身份及是否应用效果、保留起点 | 仅返回成功码而无产物证据→UNKNOWN |
| RENDERED → EVALUATED | 参考/估计对应、版本一致、保护区和包络回归、技术指标及听评 | 非目标破坏、严重伪影、无证据或不可比条件→拒绝验收 |
| EVALUATED → ADOPTED | 目标约束满足、未触及区域验证、交付依赖齐备、人工接受适用偏好 | 不通过→REVISION或ROLLED_BACK；重试预算/权利/安全边界触发停止 |
| 任意候选变化 → 依赖复核 | 输入、参数、素材、工具版本或评价协议变化时重新判断证据适用性；历史记录保留 | 不可用旧候选的评价证明新候选已合格 |

共享素材的快照不是独立备份（S088）；局部效果可能渲染/拆分clip或影响包络（S089/S090，具体版本待验证）；stem不能替代完整工程（S097）。这些来源支撑设计风险，不证明本场景曾真实执行。状态名只是L1候选。非目标区域保护应按需求定义：源对象身份/哈希、时间线/自动化等结构不变；渲染声学对比须考虑混响尾音、总线处理等传播影响，不无条件要求样本逐位相同。原始演唱评价与制作结果分开。
## 对照案例与后续验证
F+：只修改目标片段、记录完整版本/状态/验证并保留可回滚基线；F-：仅保存最终WAV就声称完成可编辑交付或只凭命令成功就通过。R+：发现副歌外电平变化，先检查包络、效果尾音、总线路由、版本/导出配置，保留多个原因；R-：只凭输出波形差异断定唯一插件故障或宣称原表演能力提升。
L2至少验证同一绑定的双向发现、状态依赖失效、非目标保护、失败拒绝、证据/版本一致和回滚。具体schema、工具与运行方案尚未冻结；真实案例、盲评、指标实现与听音实验后续审核。
