# G02 R1：等音转调的构造、分析与反例
主目标 K01.05.08.02；K01.05.15.01/.02保留子谓词，不能把父需求与子谓词计作重复事实。S284、S234 §23.2、S268 §23.3、S285 §22.6提供限定西方功能和声依据；S178/S179用于中心与借用对照。不将音乐历史上所有半音转调归入本机制。
## 明确算法候选
1. 给定实际书写、调律、低音/声部身份、和声时段与旧调证据，枚举可能根音和旧功能。保留竞争标签。
2. 12TET可对比集合等音。若属七结构{r,r+4,r+7,r+10}，候选旧V7目标r+5；将r+10按增六拼写并取候选新主音r+4（根为降六级），反向由目标t构造降六t+8及1、降3、升4；其降六也可作为属七根，查候选目标t+1。次级功能同样需原上下文，非所有属七实为转调。
3. 全减七结构{r,r+3,r+6,r+9}：逐成员作导音，向上半音形成四个目标音级；另逐成员作和弦七音向下半音形成四个属七根，再按具体新调检查。按目标调重拼根、三、五、减七；不可仅凭对称集合确定根/调式。其它解释如变音共同和弦按S285对应分类，非强制属于两大等音枢纽。
4. 查每声部具体解决、目标前属/属/主、后续新中心与句末；区分短暂主音化、借用、实际转调和直接转调。双重功能只在语境足够时提出；不确定时输出多候选/UNKNOWN；局部候选不是唯一音乐历史。
