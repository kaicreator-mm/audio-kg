# G01 候选域责任与依赖契约
DRAFT / REVIEW_REQUIRED。仅用于G01分类设计。现有15域权威不变，DOM-C01–04为候选；候选分支名称与[分类提案](domain-taxonomy-proposal.md)一致。下表箭头“消费者 → 被引用知识owner”；H=在指定任务确实需要该知识时必须先满足（不是整个子域必须先完工），O=按语境参考，不把O当H；权限/安全是操作gate，不是专业知识的循环前置。各域可以有独立研究；H仅是知识/证据依赖，非项目native DAG。若同一场景双向引用，只允许不同原子/证据的方向；同一原子不得循环以自身作为证据。缺H或冲突不能决定owner时保持UNKNOWN、记录缺口和候选，不新建重复权威。
候选分支书写别名：DOM-C01/曲目表演实践 = 提案的“曲目/表演实践”；DOM-C01/本土体系语义 = “研究伦理及本土体系语义”内本土概念部分；DOM-C04/网络同步 = “网络/同步”。别名仅为候选定位，无正式ID。引用 `Kxx` 表示该现有域的知识发现入口，不作为原子迁移目的；多分支候选须在实施前根据其后列出的谓词消歧并给唯一D4。

## 归属判定（按原子而非场景）
1. 先写待证明的谓词、对象、适用条件、证据类型及实际产物。一个场景拆为多个可证伪谓词，分别分配唯一owner。按“谁负责定义并修订此谓词的专业规则”选主责，而非谁调用工具、先看到结果或使用对象。
2. 数值/形式音高及节拍 K01；声学原理/校准 K07；通用信号/DSP K08；实际宿主/版本接口 K12；专业效果的评价协议 K10；独立认知机制 DOM-C02；具体文化/历史证据 DOM-C01；合成音色生成与patch任务 DOM-C03；场地实时系统及安全执行 DOM-C04；法律、许可及验收责任 K15。历史术语引用形式定义而不复制；K03乐器实体能力、K04表演动作、K13语言适配各负责本专业。命题涉及多个独立事实则拆分，引用原ID和版本条件。
3. 共同产物不代表共同owner；patch的参数含义归设计域，插件接口支持归K12，测量协议归K07/K10，评价的目标与实证依据分别绑定。项目域划分仅研究建议，不能替代专业来源或授权；没有产品裁决不分配新正式ID。
