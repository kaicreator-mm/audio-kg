# K02 R5：RV01 具体声调语言词曲创作决策（有限修正）
本文件补原K02.06.03.01及CO35/37，不新增主D4。原匿名X06与X07各自局部条件保留；R5实际把具体文本、读法、音符及决策绑定。任务是短型歌唱问候hook的创作预筛，不是现成作品分析或语言教学通则。统一时间为四分拍，4/4一小节，M↑=[n1:C4@0/2,n2:E4@2/2]，M↓=[n1:E4@0/2,n2:C4@2/2]（替代，只有获得改曲许可才允许）；句内无休止，句末边界在4。每词两个音节且各绑定一音；声乐实际F0曲线未指定。简报：晨间向单个初见客人问候，允许一般问候或晨间明确问候，允许礼貌形式，禁止改旋律；若用户要求必须字面表达晨间或指定敬语，则作为额外硬条件。普通话采用标准双音节分析、台湾晨间语用场景；粤语采用香港粤语教学读法、正式晨间问候。非实际口语/歌唱测量。

## 2. R5-Y：香港粤语
S331词语、语境及粤拼；S330 Appendix2调值、S327 §1.2终点关系及S307上下文限制。此处采用声明的六调分析、非入声音节，不使用普通话三声变调；题定所列常规读法，无另指定词汇变调/连读或语气变化，若实际歌手的读法不同则重新取证，尤其注意5/2可能合流，不将规范读法当个体实测。终点比较是相邻音节尾端与相邻旋律音高，不比较音节内起伏。例如 nei5 与 hou2 都为升调，但末端分别3与5；并非因同为升调就判平。相对端点数字与半音不一一对应。
