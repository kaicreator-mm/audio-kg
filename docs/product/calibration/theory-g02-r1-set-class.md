# G02 R1：十二音集合的完整显式比较规则与有限验证
目标 K01.09.04.03；不新增原子，不撤销HOLD历史记录。S282/S283/S222/S223/S281共同提供明确规则；未核Forte/Rahn原著全文，不能把项目定义等同所有历史印本或库实现。当前支持非空12音整数集合的数学约定，任意输入事件的分段与解释不是算法充分输出。
## 规范候选
输入为非空音级集合，C=0，12TET或声明12音级等价；事件到集合转换先显式选择分段、声部、重复/八度消去。整数规范化mod12，去重；不合法、空集合或未指定分段/比较约定拒绝或UNKNOWN。每个旋转升序跨八度展开，减去其起点得到偏移数组v。先比较总跨度v[last]，最小为优；相同跨度时：
- F约定（S282所述Forte左向）：依v[1]、v[2]直到v[last-1]比较，首次较小者优。
- R约定（S282/S283所述Rahn右向）：依v[last-1]、v[last-2]直到v[1]比较，首次较小者优。
- 若全部偏移相同（对称），本项目normal order选择原始起点最小者作为确定序列（S283规则4）；保留全部等价起点，不将起点变成真实主音。normal order保留真实音级及跨八度顺序。
- prime form：对原集合及I0集合分别按同一约定取normal order并归零，再用同一比较键比较，得到唯一偏移表示。同键则两偏移数组相同。输出约定ID、原集合、分段事件ID、两候选和选择依据。不得从prime form唯一恢复原事件或历史操作。

## 实际有限数学见证
执行以下同义JS比较函数与全量枚举（Builder工具环境，无第三方库、未作为运行时代码导入）。F/R各223个非空TnI代表；4095个集合×2约定×12移调×2方向=196560个不变性断言通过。S282指南所列六个类别中五组F/R表示逐项相同；第六组7-Z18有明确来源冲突：S282列F=[0,2,3,4,5,8,9]，本声明F规则算得[0,1,2,3,5,8,9]，R=[0,1,4,5,6,7,9]相同。实际枚举证实S282的F表示为本F代表的T5I，属同类但并非相同算法代表；不据此改写历史目录或声称全表一致。需固定原著/目录口径再裁决。总223包含单音及全12音，与指南208目录口径不直接等同。本验证只证明规定的有限数学域，不证明历史原著逐字算法、自动分段、音乐解释、版本化库或L2运行。
```js
const mod=x=>(x%12+12)%12;
const sort=s=>[...new Set(s.map(mod))].sort((a,b)=>a-b);
const norm=s=>s.map(x=>x-s[0]);
const lex=(a,b)=>{for(let i=0;i<a.length;i++)if(a[i]!==b[i])return a[i]-b[i];return 0};
const key=(s,m)=>{let a=norm(s),inside=a.slice(1,-1);return [a.at(-1),...(m==="F"?inside:inside.reverse())]};
const rots=s=>{let a=sort(s);return a.map((_,i)=>a.slice(i).concat(a.slice(0,i).map(x=>x+12)))};
const nf=(s,m)=>rots(s).sort((a,b)=>lex(key(a,m),key(b,m))||a[0]-b[0])[0];
const pf=(s,m)=>[norm(nf(s,m)),norm(nf(s.map(x=>-x),m))].sort((a,b)=>lex(key(a,m),key(b,m)))[0];
const classes={F:new Set(),R:new Set()}, pairs=new Map();
let checks=0;
for(let mask=1;mask<4096;mask++){
  const s=Array.from({length:12},(_,i)=>i).filter(i=>mask>>i&1);
  for(const m of ["F","R"]){
    const p=pf(s,m).join(",");classes[m].add(p);
    for(let n=0;n<12;n++)for(const sign of [1,-1]){
      if(pf(s.map(x=>sign*x+n),m).join(",")!==p)throw Error("invariance");
      checks++;
    }
  }
  const f=pf(s,"F").join(","),r=pf(s,"R").join(",");
  if(f!==r)pairs.set(f,r);
}
if(checks!==196560||classes.F.size!==223||classes.R.size!==223||pairs.size!==6)throw Error("count");
```
