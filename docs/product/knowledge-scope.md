# L1 领域范围草案

状态 DRAFT；目标是供人和 LLM 检索、理解、解释、验证及决策的专业知识资产，而非曲库/艺人百科。以下分类为可调整的内容 owner 候选，不等于 Package/Element。节点数不是质量目标。

| ID | 子域 | 知识边界 |
|---|---|---|
| K01 | 音乐基础与理论 | 音高、音程、调律、调式、节奏、记谱、和声、对位、曲式 |
| K02 | 音乐创作 | 作词、作曲、动机、主题、发展、歌词与旋律 |
| K03 | 编曲与配器 | 乐器、音域、声部、织体、风格与伴奏 |
| K04 | 演奏与音乐表现 | 演奏法、力度、速度、律动、即兴、排练 |
| K05 | 声乐科学 | 发声、呼吸、共鸣、声学、语音/音素、声区及个体差异 |
| K06 | 声乐实践与教学 | 音准、节奏、咬字、表情、训练、反馈、安全转介 |
| K07 | 声学与听觉 | 波形、频谱、心理声学、音色、空间声学 |
| K08 | 数字音频与录音 | 采样、编码、信号链、录音、DSP、修复、音轨分离 |
| K09 | 音乐制作与后期 | DAW、工程、编辑、修音、混音、母带、交付 |
| K10 | 音乐理解与评价 | MIR、转录、结构、歌词对齐、听评、指标及局限 |
| K11 | AI 音乐与歌声生成 | 表征、模型、生成、SVS/SVC、训练、适配、评估 |
| K12 | 音乐软件与编排 | 工具能力、接口、格式、Agent/MCP、工作流及故障处理 |
| K13 | 文化、语言与本地化 | 非西方音乐系统、跨语言演唱、缅甸语案例；避免单一文化外推 |
| K14 | 音乐教育与学习 | 乐理、听觉、演奏教育、学习设计与评估；声乐专项属 K06 |
| K15 | 音乐生产管理与权利 | 角色、交付、版本、来源、授权、音色许可、数据治理 |

边界：K05 生理与声学机制、K06 教学操作；K07 通用物理/感知、K08 数字技术、K09 制作决策；K10 评价方法、K11 AI 实现机制、K12 软件版本能力。跨域仅引用，不复制权威主张。具体细粒度清单和 ownership 冲突由 L1 审核。音乐史/作品/艺术家仅在解释专业知识或文化背景时纳入；不批量构建歌曲目录。不诊断疾病，不收集个人声音，不训练模型，不做应用、数据库部署或 SDK 集成。

## Competency questions (CQ，草案)
CQ01 给定调律、音高体系与音程，如何解释/计算音高关系？反例：非十二平均律。
CQ02 给定和弦、调式和曲式，哪些分析合理、哪些条件下不成立？
CQ03 给定旋律、乐器音域和表现意图，如何决定配器并检查冲突？
CQ04 给定歌词、音节、语种、节拍和旋律，如何找出对齐约束与冲突？
CQ05 音高、声区、共鸣、音色之间是什么关系？哪些只能从录音观察而不能诊断？
CQ06 音准不稳时有哪些候选解释、如何测量、何时需教师或专业医疗人员？
CQ07 从录音中如何区分基频、谐波、共振峰及噪声？哪些输入使检测失败？
CQ08 如何区分采样削波、响度、真峰值、动态范围；如何选择不同输出规范？
CQ09 什么输入适合 SVS、SVC、TTS 或完整歌曲模型？输出、局限和授权条件？
CQ10 如何根据单轨/多轨、失真、噪声选择分离与修复工具并验证副作用？
CQ11 如何区分模型报告指标、独立听评和审美偏好；何时不能比较？
CQ12 一个跨语言翻唱任务如何选择歌词适配、音轨、人声、混音与质量检查步骤？
CQ13 如何追踪一条主张的来源版本、原文定位、反例、冲突、审核与替代历史？
CQ14 如何判定某工具是否真实支持指定版本、接口、语言与控制能力？
CQ15 如何从教育目标选择练习及可观测反馈，同时保留个体/流派差异？
CQ16 当音色、旋律或结构仅需局部修改，如何保持其余工程状态并验证？
CQ17 某种音乐关系是定义、规范、统计规律还是文化习惯？能否用于自动推理？
CQ18 能否给出非西方/缅甸音乐案例中与通用规则不一致的证据，而非强制映射？

首版验收：冻结 CQ 对应领域覆盖矩阵；每项至少有可追踪的正例、适用条件、负例或明确 UNKNOWN；图谱可按 ID 查询来源、关系、限制与冲突；跨域查询有可复核推理路径；专家内容审核与结构验证分离。
